# yardmask

Yard digests and mask fingerprints for local integrity checks.

**Site:** https://theworker02.github.io/yardmask/

## Install / run

```bash
git clone https://github.com/theworker02/yardmask.git
cd yardmask
node src/cli.js
node --test
```
